# Life & Fitness Dashboard

개인용 라이프 & 피트니스 미니멀 대시보드 (React + Vite + Tailwind CSS)

## 접속 URL (GitHub Pages)

**https://kriskang02-max.github.io/life-fitness-dashboard/**

Settings → Pages → Source: **GitHub Actions** (또는 `gh-pages` 브랜치)

## 로컬 실행

```bash
npm install
npm run dev
```

## 기능

- Daily Actions (4개 체크박스)
- Weekly Engine (KPI + Chart.js)
- Monthly Archive (히트맵 + 마인드 아카이브)
- localStorage 영구 저장 + JSON 백업/복원

## 스택

React 19, Vite, Tailwind CSS v4, Lucide React, Chart.js
